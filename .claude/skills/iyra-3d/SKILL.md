## 3D RULES

Use React Three Fiber for 3D.

Use Drei for reusable Three.js helpers.

Prefer one primary Canvas.

Keep WebGL and DOM responsibilities separate.

Do not put important SEO content inside Canvas.

Use 3D to support storytelling rather than adding 3D unnecessarily.

---

## ANIMATION

Use GSAP for complex timelines.

Use ScrollTrigger for scroll-driven sequences.

Use Lenis for smooth scrolling.

Animation must feel cinematic.

Avoid excessive bouncing, elastic animations and unnecessary effects.

---

## PERFORMANCE

Always consider GPU performance.

Use:

- lazy loading
- GLB/GLTF
- compressed textures
- instancing
- LOD
- adaptive quality
- DPR limits
- reduced particle counts on mobile

Never allow 3D to make the website unusable.

---
